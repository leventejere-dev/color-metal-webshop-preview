## 4. Observații pentru producție

- Fotografiile stock ilustrează **forma** produsului; unele arată oțel, nu aluminiu/cupru (ex. profile U, colțare, bare pătrate).
  Pentru varianta de producție recomandăm fotografii proprii Color Metal ale semifabricatelor din stoc.
- `profile_t-close.jpg` prezintă un raft cu profile mixte (T, L, platbandă) – nu există fotografie stock gratuită dedicată profilului T;
  forma este redată exact de ilustrația tehnică oficială și de previzualizarea SVG live din configurator.
- Fonturile: **Montserrat** (SIL Open Font License 1.1), pachet npm `@fontsource-variable/montserrat`, servit local.
- Pictogramele UI: **lucide-react** (licență ISC).
